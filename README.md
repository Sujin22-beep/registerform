## Registration Form – Project Description

I have created a simple and user-friendly Registration Form using HTML, CSS, and JavaScript. The form consists of three fields: Name, Email, and Password.

JavaScript is used to perform real-time validation while the user enters the details. The Name field displays an error message if it is left empty. The Email field checks whether the entered email address follows a valid format. The Password field ensures that the password contains a minimum of six characters.

The Submit button remains disabled until all three fields are correctly validated. Once all the inputs are valid, the Submit button becomes enabled. After successful submission, a confirmation message is displayed, and the form fields are reset.

This project helped me understand HTML form creation, CSS styling, JavaScript functions, event listeners, conditional statements, regular expressions, and real-time form validation.
